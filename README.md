# Cameren Downs — Engineering + Security Portfolio

A responsive, engineering-inspired personal website built with HTML, CSS, and JavaScript. No build tools or paid hosting required.

## Preview on your computer

Download and unzip the folder, then double-click `index.html` to open it in your browser. The design will work locally (the optional Google Fonts download requires internet access).

## Personalize before publishing

1. Open `script.js` in Notepad or VS Code and fill in the `PROFILE` object with your actual GitHub profile URL, LinkedIn profile URL, and contact email. Blank links display a helpful message rather than sending people to the wrong profile.
2. Review `index.html` for accuracy, especially the About, Skills, Experience, and Projects sections.
3. The three project cards are **planned project ideas**, not finished projects. Replace them with your own genuine projects, screenshots, links, and outcomes as you build them.
4. Add a sanitized, public-ready resume only when you are comfortable sharing it; never include sensitive company configurations, customer information, keys, internal URLs, or real security event logs.
5. `styles.css` holds the design colors at the top, in the `:root` section.

## Publish free on GitHub Pages (using the GitHub website)

1. Log into GitHub and create a **new public repository** named `YOUR-USERNAME.github.io`, substituting your exact GitHub username.
2. Click **Add file → Upload files**. Upload `index.html`, `styles.css`, `script.js`, `.nojekyll`, and `README.md` directly into the repository root. Commit the changes to `main`.
3. Open your repository's **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**, then select `main` and `/(root)` and click **Save**.
5. Visit `https://YOUR-USERNAME.github.io/`. GitHub notes that changes can take up to 10 minutes to publish.

For the current GitHub instructions, see: https://docs.github.com/en/pages/quickstart

## Update your portfolio later

In your GitHub repository, click a file → pencil icon to edit → **Commit changes**. Changes will publish automatically. Or edit locally and upload the files again.

## Files

- `index.html` — page content and structure
- `styles.css` — responsive styling
- `script.js` — navigation and editable contact profile
- `.nojekyll` — use the static site directly
